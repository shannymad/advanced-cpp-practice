# Queue

В этой задаче вам нужно реализовать упрощённый аналог шаблонного класса `std::queue`, а именно очередь с типом элементов `int`.

## Как решать эту задачу?

Очередь — это структура данных, работающая по принципу **FIFO** (First In, First Out): первый добавленный элемент извлекается первым. Аналогия — очередь в магазине: кто первый встал, тот первый и выходит.

В отличие от стека, где добавление и удаление происходят с одного конца, в очереди добавление идёт **в конец**, а удаление — **из начала**.

## Интерфейс

* Конструктор по умолчанию.
* Конструктор копирования.
* Конструктор перемещения.
* Операторы присваивания, копирующий и перемещающий.
* Деструктор.
* Метод `Swap`, принимающий другую очередь по ссылке и меняющий содержимое местами.
* Метод `Push`, добавляющий элемент в конец очереди.
* Метод `Pop`, удаляющий элемент из начала очереди.
* Метод `Front`, возвращающий ссылку на первый элемент (константный и неконстантный).
* Метод `Back`, возвращающий ссылку на последний элемент (константный и неконстантный).
* Метод `Size`, возвращающий число элементов в очереди.
* Метод `Empty`, возвращающий `true`, если очередь пуста.
* Метод `Clear`, опустошающий очередь.

## Примечания

* Все операции `Push`, `Pop`, `Front`, `Back`, `Size`, `Empty` должны работать за O(1) (амортизированно для `Push`).
* Важное требование — все ссылки на элементы очереди должны оставаться валидными при вставках/удалениях (кроме ссылок на удаляемые элементы).
* В этой задаче запрещено использование стандартных контейнеров.

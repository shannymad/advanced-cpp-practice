# Stack

В этой задаче вам нужно реализовать упрощённый аналог шаблонного класса `std::stack`, а именно стек с типом элементов `int`.

## Как решать эту задачу?

Стек — это структура данных, работающая по принципу **LIFO** (Last In, First Out): последний добавленный элемент извлекается первым. Аналогия — стопка тарелок: кладём сверху, берём сверху.

## Расширение массива

При расширении:

1. Новая вместимость = `capacity_ * 2` (или 1, если было 0).
2. Выделяем новый массив.
3. Копируем элементы из старого в новый.
4. Удаляем старый массив.
5. Обновляем `data_` и `capacity_`.

Важно: при расширении **сами элементы не перемещаются в памяти вызывающей стороны** — они копируются во внутренний массив. Ссылки на элементы стека не должны сохраняться между операциями `Push`, потому что `Push` может вызвать реаллокацию.

## Интерфейс

* Конструктор по умолчанию.
* Конструктор копирования.
* Конструктор перемещения.
* Операторы присваивания, копирующий и перемещающий.
* Деструктор.
* Метод `Swap`, принимающий другой стек по ссылке и меняющий содержимое местами.
* Метод `Push`, добавляющий элемент на вершину стека.
* Метод `Pop`, удаляющий элемент с вершины стека.
* Метод `Top`, возвращающий ссылку на вершину стека (константный и неконстантный).
* Метод `Size`, возвращающий число элементов в стеке.
* Метод `Empty`, возвращающий `true`, если стек пуст.
* Метод `Clear`, опустошающий стек. `Size` должен стать нулевым.

## Примечания

* Все операции `Push`, `Pop`, `Top`, `Size`, `Empty` должны работать за O(1) (амортизированно для `Push`).
* В этой задаче запрещено использование стандартных контейнеров.
